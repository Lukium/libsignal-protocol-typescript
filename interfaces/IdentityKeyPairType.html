Interface IdentityKeyPairType<T>

The long-term identity key. As of the WebCrypto backend, an identity is TWO keys (see README "Cryptographic Backend"): an X25519 key for X3DH Diffie- Hellman (pubKey/privKey, same role and 33-byte DJB form as before) and an Ed25519 key for signing signed-prekeys (signingPubKey/signingPrivKey, raw 32-byte). This replaces the single-key XEdDSA identity.
